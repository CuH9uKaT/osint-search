# Deploy checklist

## Render environment

Required:

- `APP_PASSWORD` — your private login password
- `SECRET_KEY` — generated by Render

Mode-specific defaults:

- `SOCIAL_SITE_TIMEOUT=10`
- `SOCIAL_SEARCH_TIMEOUT=120`
- `COMMUNITY_SITE_TIMEOUT=10`
- `COMMUNITY_SEARCH_TIMEOUT=150`
- `GAMING_SITE_TIMEOUT=10`
- `GAMING_SEARCH_TIMEOUT=150`
- `DEVELOPER_SITE_TIMEOUT=12`
- `DEVELOPER_SEARCH_TIMEOUT=180`
- `FULL_SITE_TIMEOUT=12`
- `FULL_SEARCH_TIMEOUT=240`
- `SHERLOCK_WORKERS=20` (informational/forward-compatible with pinned 0.16.0; effective internal pool is 20)

## First use

1. Open the service URL.
2. Log in.
3. Select **📱 Соцмережі** first.
4. Enter a test username.
5. Confirm results appear progressively.
6. Test CSV export.

## STOP production test

1. Select **🌐 Повний**.
2. Start a search.
3. Wait 15 seconds.
4. Press **Стоп**.
5. Confirm partial results remain and status is **Скасовано**.

## Diagnostics

Open the gear button and confirm:

- Sherlock version is shown
- catalog is `ok: true`
- SHA-256 prefix is present
- category counts are present
- requested/effective worker values are shown
